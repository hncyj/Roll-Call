# Windows 打包指南

当前发布目标：**Windows 10 / 11，64 位，Python 3.11**。本项目不再承诺 Windows 7 兼容。Windows EXE 应在 Windows 上构建；本地 macOS 测试不能代替 Windows 发布验证。

## 准备环境

安装 Python 3.11，启用安装器中的 Add Python to PATH。在项目目录的命令提示符执行：

```cmd
python --version
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements-build.txt -r requirements-dev.txt
```

确认 `python --version` 显示 3.11.x。依赖版本以 requirements 文件为准，打包器使用 PyInstaller 6 或以上。UPX 是可选压缩工具，自动构建会安装。

## 先测试再打包

```cmd
python -m pytest -q
pyinstaller --clean rollcall.spec
```

仅在测试全部通过后分发 `dist\随机点名.exe`。

GitHub Actions 中，普通代码推送 / PR 运行测试；推送 `v*` 标签或手动运行 Build on Windows 会执行回归测试、构建 EXE、检查进程启动后存活，并上传构建产物。存活检查不等同于完整人工验收。

## 分发与升级

将 EXE 放在用户可写的普通文件夹中。首次运行会创建默认班级及 `rollcall_data.json`。

分发时建议一并附上 [程序使用说明（PDF）](程序使用说明.pdf)，供使用者查阅 Excel 初始化和 U 盘课堂操作步骤；[Markdown 源文档](程序使用说明.md)保留供后续维护。

```text
随机点名/
├── 随机点名.exe
├── rollcall_data.json       # 默认名单、评分和轮次
└── rollcall_settings.json   # 更换路径后生成，记录实际数据位置
```

升级前退出旧程序并备份 JSON 文件。升级只替换 EXE，保留数据和路径设置；不要用空白样例覆盖用户文件。若使用外部数据路径，还应备份那个数据文件。程序同目录的锁文件由程序管理。

## 发布前人工检查

1. 新建两个班级，导入学号为文本的 Excel 名单（首行表头，前两列为学号和姓名）。
2. 完成一次随机点名但不保存评分，退出重开，确认该学生仍在本轮已点列表。
3. 抽完一轮，确认随机与手动均不能重复点名；确认重置后才可开始新一轮。
4. 修改数据路径，点名 / 评分后重启，确认路径、轮次及记录恢复。
5. 动画期间切换班级，确认不会把原班学生记入新班。
6. 增删改学生、重新导入名单，确认名单同步，旧轮次与学号关联不丢失。
7. 导出本班和全部班级成绩单，检查 Excel 内容。

## 常见问题

- **提示找不到已设置的数据文件**：连接原存储设备或恢复提示位置的文件；不要为了启动而删除路径设置，以免误读旧数据。
- **旧版重启后记录变少**：查找先前选择的自定义 JSON，在设置中选择它以重新打开。当前默认文件与自定义文件不会自动合并。
- **提示目录不可写或无法保存**：将完整程序文件夹放到可写位置，检查磁盘空间 / 外部设备。写入失败不会显示保存成功。
- **提示程序已运行**：使用已打开的窗口。不要通过复制程序目录来同时编辑同一份数据。
- **需要排查启动异常**：本版本会弹出数据加载错误。EXE 默认无控制台，不能假设从 cmd 启动就能看到 traceback；必要时用同版本 Python 执行 `python main.py` 排查。
