# 随机点名系统 · Windows 打包指南

## 前置说明

- 打包必须在 **Windows 系统**上进行，macOS 无法产出 `.exe`
- 目标运行环境：Windows 7 / 10 / 11
- 全程在命令提示符（`cmd`）中操作，无需管理员权限

---

## 第一步：安装 Python 3.8

1. 打开浏览器，访问：https://www.python.org/downloads/release/python-3817/
2. 页面拉到底部，下载 **Windows installer (64-bit)**：`python-3.8.17-amd64.exe`
3. 运行安装程序，**务必勾选底部的 "Add Python 3.8 to PATH"**，再点 Install Now
4. 安装完成后打开 `cmd`，验证：

```cmd
python --version
```

应显示 `Python 3.8.17`

---

## 第二步：获取项目代码

将整个项目文件夹复制到 Windows 上，例如放到：

```
C:\rollcall\
```

确认目录结构如下：

```
C:\rollcall\
├── main.py
├── rollcall.spec
├── requirements.txt
├── requirements-build.txt
├── assets\
│   └── icon.ico
└── app\
    └── ...
```

---

## 第三步：创建虚拟环境并安装依赖

在 `cmd` 中执行：

```cmd
cd C:\rollcall
python -m venv venv
venv\Scripts\activate
pip install --upgrade pip
pip install -r requirements-build.txt
```

> 安装过程需要网络，共下载约 200MB，耐心等待。

安装完成后验证：

```cmd
pip show pyinstaller
```

应显示 `Version: 6.3.0`

---

## 第四步：执行打包

```cmd
pyinstaller rollcall.spec
```

打包过程约 1~3 分钟，完成后出现：

```
Building EXE from EXE-00.toc completed successfully.
```

产出文件位于：

```
C:\rollcall\dist\随机点名.exe
```

---

## 第五步：准备发布目录

打包产出的是**单个 exe 文件**，发布时只需创建一个干净的文件夹：

```
随机点名\
├── 随机点名.exe        ← 从 dist\ 复制过来
└── rollcall_data.json  ← 如有历史数据，放在同目录；没有则首次启动自动创建
```

将这个文件夹发给使用者即可。

---

## 第六步：目标机器的运行前提

### Windows 10 / 11
无需任何额外操作，直接双击运行。

### Windows 7
需要提前安装以下运行时（均为免费官方包）：

| 组件 | 说明 |
|------|------|
| **Microsoft Visual C++ Redistributable 2019 (x64)** | Qt5 依赖，必须安装 |

下载地址：https://aka.ms/vs/16/release/vc_redist.x64.exe

安装完成后重启，再双击 exe 即可。

---

## 常见问题

**Q：双击 exe 闪退没有任何提示**
打开 `cmd`，切换到 exe 所在目录，直接运行查看错误信息：
```cmd
cd C:\Users\xxx\随机点名
随机点名.exe
```

**Q：打包时报 `ModuleNotFoundError`**
在虚拟环境中补充安装缺失的包后重新打包：
```cmd
pip install <缺失的包名>
pyinstaller rollcall.spec
```

**Q：打包后中文界面乱码**
确认系统区域设置为中文（控制面板 → 区域 → 管理 → 更改系统区域设置 → 中文简体）

**Q：想重新打包（代码有更新）**
先删除旧的构建缓存再打包：
```cmd
rmdir /s /q build dist
pyinstaller rollcall.spec
```
